
# Personal Portfolio

## About the Project

This is my personal portfolio website. It introduces me, my skills, courses, projects, hobbies, and contact information.

I created this project using HTML, CSS, and JavaScript to practice web development and present my technical skills.

## About Me

 A Cybersecurity diploma graduate. I am interested in network security, Linux, and Security Operations Center (SOC).

I enjoy learning new technologies, improving my technical skills, and working on projects. My goal is to gain practical experience and develop my skills in cybersecurity.

## Technologies Used

- HTML5
- CSS3
- JavaScript 
  

## Website Sections

### 1. About Me
A personal introduction with my profile photo and a short biography.

### 2. Skills and Courses
Displays my technical skills and courses.

### 3. Projects
Showcases my projects with links to GitHub repositories.



### 5. Contact Me
Includes a contact form for visitors.

## Features

- Responsive design for desktop and mobile devices.
- Navigation bar linking to different sections.
- Interactive theme switcher using JavaScript.
- Contact form with basic input validation.
- Smooth scrolling between sections.

## How to Run the Project

1. Download or clone the project repository.
2. Open the project folder.
3. Make sure the profile photo is inside the `assets` folder.
4. Open `index.html` in your web browser.
